## 1. お願いは2つだけ

### ① Workerの環境変数に、この本番URLを設定してください

```
https://allverse.onrender.com/api/presence.json
```

- 公開GETです。認証は不要
- Renderの無料プランなので、15分アクセスがないとスリープします。復帰は数十秒
  （そちらで4秒キャッシュ＋直近キャッシュ返却を実装済みと伺っているので、そのままで大丈夫だと思います）
- 稼働確認用: `https://allverse.onrender.com/api/status`
  （`commit` フィールドに、いま動いているGitのコミットが出ます）

### ② 座標の吸収処理を入れていたら、外してください（← 重要）

**`x`/`z`/`r` は VRChatワールド座標そのものになりました。** 受け取った値をそのまま置いてください。

`PRESENCE_SPEC.md` v0.3 §2.3 では「原点＝メインステージ中心の床面」「ズレはVRC側ギミック内の
定数（オフセット＋回転）で吸収する」と決めていましたが、**この取り決めを撤回します**。
もし既にオフセット定数を実装済みなら、**入れたままだと二重にズレます**。

## 2. 具体的な数値（これだけ見れば足ります）

presence.json の `web[]` は、こういう値で届きます。

| フィールド | 内容 |
|---|---|
| `x` / `z` | **VRChatワールド座標**（メートル・小数1桁）。そのまま `transform.position` に入れてOK |
| `r` | **VRChatのY回転**（度・0〜359の整数）。そのまま `rotation` に入れてOK |
| `y`（高さ） | 送りません。従来どおり床基準で置いてください |

**ブラウザ勢が出現しうる範囲**（clubVERSE の客席部分）

| | VRCワールド座標 |
|---|---|
| X | −234 〜 −196 |
| Z | −88.4 〜 −66.9 |
| 広さ | 38m × 21.5m |
| 会場中心 | (−209.0, −71.91) |
| 会場入口 | (−213.9, −61.6) |
| ステージ背面ガラス付近 | (−213.9, −99.1) |

この範囲の外には出ません（ブラウザ側で移動範囲を矩形に制限しているため）。

## 3. なぜ変わったのか（読まなくても作業できます）

2026-07-30、ブラウザ版の会場を**仮ワールドから、VERSE CITY2025 の clubVERSE 実物に差し替えました**。
そちらの書き出し用シーン（`club VERSE260729 EXPORT.unity`）から FBX → Blender → GLB に変換したもので、
**メッシュはVRChatのワールドと同一**です。

変換時に「会場の中心を原点へ寄せる」処理を入れたためVRC本体とズレていましたが、その寄せ幅が
書き出しログに残っており、Unityシーンから読んだ実測値とも一致したので、送信直前に戻す形にしました。

**照合結果**

| ランドマーク | Unityシーンの実測 | 変換して得た値 | 差 |
|---|---|---|---|
| 会場入口（club_外観） | (−213.90, −61.60) | (−213.90, −61.60) | **0.00m** |
| STAGE BACK GLASS (1) | (−213.92, −99.15) | (−213.90, −99.10) | 0.02 / 0.05m |

変換式（`server/server.js` の `toVrcX` / `toVrcZ` / `toVrcRot`）:

```
VRC.X = -(ブラウザx) - 209.0
VRC.Z =  (ブラウザz) - 71.91
VRC角度 = -(ブラウザ角度)
```

X軸と回転の符号が反転するのは、Unity（左手系）から書き出して three.js（右手系）へ
取り込んだためです。実際にWebSocketで3人ぶん流し込み、下記の出力になることを確認済みです。

```
ブラウザ 入口(4.90, 10.31) 0度      → (-213.9, -61.6) 0度
ブラウザ ステージ前(4.88, -16.5) 180度 → (-213.9, -88.4) 180度
ブラウザ 西端(-13, 5) 90度           → (-196, -66.9) 270度
```

`PRESENCE_SPEC.md` §2.3 も更新済みです（**スキーマ `v=1` は変えていません**。
フィールドの構成は据え置きで、入る値の座標系だけが変わりました）。
