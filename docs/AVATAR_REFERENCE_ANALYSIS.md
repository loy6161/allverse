## ここから分かった最大の教訓

### 1. パーツを積むのではなく、1枚のメッシュを折り曲げて作っている
自作は「球・円柱・円錐を数十個並べる」方式だった。参考モデルは**全身が1つの連続したメッシュ**。
だから継ぎ目が無く、シルエットが繋がって見える。
**これが「パーツを並べただけに見える」の正体**だった。

### 2. 三角形334枚しかない ＝ 面の一枚一枚に意味がある
髪は「毛束を並べる」のではなく、**数枚の大きな三角形で塊を表現**している。
面が少ないほど、一枚の角度と輪郭が効いてくる。逆に言うと、
**細かい部品をたくさん足すほど"ローポリらしさ"も"可愛さ"も失われる**。

### 3. 色は形ではなくテクスチャで付けている
256×256のアトラス1枚に、肌・服・髪・目をすべて配置。
自作は「パーツごとにマテリアルを変える」方式だったので、
色の境界＝メッシュの境界になり、造形の自由度を失っていた。
テクスチャなら**1つの面の中で色を切り替えられる**（例: 服の切り替え線、目の位置）。

### 4. 目は「テクスチャに描く」だけでよい
参考モデルの顔は平らな面にテクスチャ。立体的な目のパーツは無い。

## 自作を作り直すときの方針

1. **全身を1メッシュで作る**（少なくとも 体／髪／小物 の3つ以内）
2. **三角形は300〜600を目標**（今の1/4以下）
3. **256〜512の texture atlas を1枚**作り、色はすべてそこで塗る
4. 面を減らす代わりに、**輪郭の角度で情報を出す**（髪の毛先を尖らせる等）
5. ボーンは後回しでよい（Web側はパーツ回転でも動かせる）

→ 現状のthree.jsでのプリミティブ積み上げは、**そもそも作り方が違った**。
   Blenderで1枚のメッシュとして作り、glTFで書き出す方式に切り替えるのが正しい。

## 追記（2026-07-29 v3）: 「かわいいローポリの顔」の一貫性

loyさん提供の追加参考画像4枚（ずんだもん風・表情セット×2・RINFEIKUN）から抽出した共通ルール。
v2の「房を並べた前髪」はこれに反していた。

1. **前髪は一枚の塊**。生え際は「サイドが低く下がり、中央にVが1本、目の間まで降りる」M字。
   房の集合ではない。隙間の影も作らない
2. **目は低く・左右に離す**。中央Vの両脇の窪み（明るい領域）に置く。小さめの縦長矩形
3. **顔は完全にフラット**。面ごとの陰影ノイズは可愛さを壊す（肌はスムーズシェーディングにする）
4. **髪シルエットは大きい塊少数**（お団子2つ＋アホ毛1本程度）。毛先は尖らせるが複雑にしない
5. **手足は先の尖った単純なくさび**。手・足のパーツは作らない。チークは目の斜め下に小さく

### 実装上の教訓（球面に前髪を沿わせるとき）
大きな三角形の頂点だけを球面に投影すると、**面の中央が弦のたわみで球にめり込んで隠れる**。
中点分割で2回細分化してから投影する（lp.js の subdivide4）。
