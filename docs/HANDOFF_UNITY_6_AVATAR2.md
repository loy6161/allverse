# 申し送り⑥: アバターの見た目が増えました（`av` に `ht` を追加）

作成: 2026-08-03 ／ 発行元: ALLVERSE WEB側 ／ 宛先: Unity/VRChat側（VERSE CITY2025）
種別: **スキーマ変更の事前共有**（返答⑤の取り決めに従うもの）

---

## 一言でいうと

**`av` に身長 `ht` が増えました。** あわせて**肌の色が1つ増え**、**アクセサリーが6種増え**ました。

**いま何もしなくても壊れません。** `ht` は任意で、無ければ従来の背丈として扱う設計です。
ただしプロキシアバターの見た目を合わせるなら、下記に対応してください。

---

## 変更点

### 1. `av.ht` を追加（身長）

```json
"av": { "h":"bob", "o":"middle", "ac":"halo", "hc":3, "sc":4, "bc":8, "ec":2, "pl":5, "ht":"mid" }
```

| 値 | 意味 | 倍率 | 実寸のめやす |
|---|---|---|---|
| `"small"` | 小さい | ×0.88 | 約1.06m |
| `"mid"` | ふつう（**既定**） | ×1.00 | 約1.21m |
| `"big"` | 大きい | ×1.13 | 約1.36m |

- **省略・未知の値はすべて `mid` 扱い**にしてください（こちらもそうしています）
- ブラウザ側は**アバター全体の拡大率**として実装しています。頭上の名前・吹き出し・持ち物も一緒に拡縮します

### 2. `av.bc`（肌の色）の範囲が 0–7 → **0–8** に

- 末尾に**白（`#fdf1e6`）**を1つ足しただけです。**既存の番号の意味は変わっていません**
- 8 を受けたときに白として扱えないと、その人だけ肌色が既定に落ちます

### 3. `av.ac`（アクセサリー）に6種追加

| id | 内容 | 見た目 |
|---|---|---|
| `tail` | しっぽ | 腰の後ろ。**髪と同じ色** |
| `wing` | 羽 | 背中。光る白 |
| `halo` | 天使の輪 | 頭上に浮く輪。光る白 |
| `ribbon` | リボン | 頭の右。**服と同じ色** |
| `sunglasses` | サングラス | 黒 |
| `glasses` | メガネ | 黒フレーム |

- 従来どおり `none` / `kemo` / `ahoge` も有効です
- **未知のidは `none` 扱い**でお願いします（こちらもそうしています）

**色はマテリアル名で塗り分けています**（既存パーツと同じ約束）。今回2つ増えました。

| マテリアル名 | 色 |
|---|---|
| `MatHair` | 髪の色（しっぽ） |
| `MatCloth` | 服の色（リボン） |
| **`MatAcc`** | **ほぼ黒の固定色**（メガネ・サングラス）※新規 |
| **`MatGlow`** | **光る白の固定色**（羽・天使の輪）※新規 |

## あわせてお知らせ（スキーマ変更ではないもの）

- **`penlight` の長さを 4.0秒 → 0.6秒に変えました。** 「持ち上げてから2往復」をやめて
  「1往復だけ」にし、連打で振り続けられるようにしたためです（loyさんの要望）。
  そちらは `emd` を見ていれば自動で追随します
- **スペシャルエモートを6種追加**しました。`em` に以下が流れることがあります:
  `fist`(1.4秒) / `smile`(2.2) / `headbang`(2.0) / `star`(2.4) / `firework`(2.6) / `cheers`(2.2)
  - **未知のidは `none` 扱い**で構いません。対応するかはそちらの判断でお願いします
  - 粒（星・花火・ニコニコ）はブラウザ側では板の絵で出しています。VRC側は好きな表現で構いません
