### 入口の鍵（2026-07-31追加）
- 開発中に直リンクで来られたくない、という要望への対処。`ENTRY_KEY` を設定すると
  **`?k=<鍵>` が無いアクセスは真っ白な404**になる（サービス名も案内文も出さない）
- 案内は `https://allverse.onrender.com/?k=<鍵>`。短縮URL（short.gy）の転送先をこれにする。
  **鍵を変えれば、配ったURLもブックマークも一斉に無効**＝いつでも閉じられる
- **「short.gy 経由でしか入れない」は原理的に不可能**と実測で確認（2026-07-31）。
  short.gy は `302 Found` ＋ 本文なしを返すだけで、転送後はブラウザが直接つなぐ。
  「どこから来たか」はこちらに届かず、本物のURLもアドレスバーに出る。だから鍵方式にした
- 鍵をかけるのは**入口のHTMLだけ**。JSや3Dモデル単体では会場に入れないので閉じない
  （閉じると鍵つきで開いたページの読み込みまで壊れる）
- ⚠ **`/api/presence.json` には絶対に鍵をかけない**（VRChat側のWorkerが取りに来ている）
- 未設定なら今までどおり誰でも入れる（移行の安全策。`GOOGLE_CLIENT_ID` と同じ考え方）
- ⚠ **秘密を守る仕組みではない**。鍵つきURLを転送されれば入れる。守るのは公開の可否
- WebSocketには鍵をかけていない（うっかり防止が目的のため）
- 自動テスト `test_entrykey.js`：鍵あり13項目・鍵なし2項目PASS。手順は `SETUP_AUTH.md` C-4

### 実戦運用のための機能（2026-07-29追加）
- **イベント ＞ ルームの二層構造**。イベントが動画の持ち主で、同じイベントなら全ルームが同じ映像・同じ再生位置
  - 常設イベント `main`（VERSE CITY）は必ず存在し削除不可。特別イベントは管理者が画面から作成
  - ルーム一覧から好きな部屋へ移動できる（🚪ボタン）。呼び名は「ルーム」に統一（＝VRChatのインスタンス）
- **Googleログイン**（任意）。ログインしないゲストは閲覧のみで、チャット・エモート・見た目変更ができない
- **管理者権限**。動画の入力・再生操作・イベント作成は管理者だけ。音量とミュートは各自ローカル
- **全ルームに現れるメンバー**（admin/vip）。姿・チャット・エモートが同じイベントの全ルームへ届く
- **ローカルチャット**。ワールド内だけに届く発言が既定。配信への送信は管理者のみ（YouTube送信自体は未実装）
- **イベントの永続化**（Turso）。Renderのスリープでも消えない。未設定ならメモリ運用に自動フォールバック
- 移行の安全策: `GOOGLE_CLIENT_ID` 未設定の間は**全員が今まで通り使える**（権限制御は設定した瞬間から効く）
- アバターを**Blender製GLB**に全面置換（髪型6×服装3×アクセ3×色14段階）。生成器は `tools/gen_avatar_obj.mjs`
- 床の鏡面反射のギラつきを解消（全角度で白飛び0.4%以下）
- 自動テスト4本72項目がログイン有効/無効の両方でPASS

### VRC客席の吹き出し（`web[].c`）を有効化（2026-08-03・申し送り⑦）

ブラウザ会場では吹き出しが出るのに、VRC客席のプロキシだけ黙っている状態を解消した。
`presence.json` の `c` は元から v=1 に**任意項目として定義済み**だったので、**契約の変更なし・版上げなし**。
Worker は `web[]` を素通ししているので**Worker側の改修もゼロ**。

**★ 出すのは YouTube由来の発言だけ。会場の独自チャットは絶対に載せない。**
`presence.json` / `live.json` は認証なしの公開URLなので、会場チャットを載せると
「入場者どうしの会話」が外から全部読めるようになる。YouTubeのコメントは元から公開の場での
発言なので再掲しても新たに漏れるものが無い、という線引き（`docs/HANDOFF_UNITY_7_BUBBLE.md`「決定2」）。

- 実装: `lastChat` に出どころの札 `src`（`'yt'` / `'local'`）を持たせ、`'yt'` のときだけ `c` を出す
  - ⚠ 判定は**肯定形**（`src === 'yt'`）で書く。否定形にすると将来 src が増えたとき漏れる側に倒れる
- **サイズ実測**: 60人全員が40文字＋エモートを同時に出している状態で **19.1KB**（上限30KB）。
  12文字の日本語名なら +約1.4KB で約20.5KB
- テスト: `server/test_bubble_presence.js`（18項目）。会場チャットが漏れないことを2経路で見張る
- ⚠ **VRC側の吹き出し（Udon の TMP）はまだ無い**ので、絵としてはまだ出ない。申し送り⑦の返答待ち
- ⚠ **NGフィルタは無い**。YouTube側で後から消された発言は最大30秒だけ残る（申し送り⑦に明記済み）
