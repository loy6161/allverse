### 1. チャットが動画コントローラーと重なっている

  覆って設定画面を閉じられなくなった → `bottom:110px` へ退避）。
  **場当たりに逃がすのではなく、下記7の「置き場所の整理」とまとめて解くべき**

### 2. チャットの文字が白くて読めない → ダークモードにする
- 背景が明るいと文字が飛ぶ。会場は夜のクラブなので暗い前提の配色に揃える

### 3. チャットウィンドウをドラッグで移動・リサイズできるようにする

### 4. 移動は各ウィンドウでできた方がいいかもしれない
- 「かもしれない」＝**未確定**。3をやってみてから判断する
- 対象になりうるもの: 会場チャット / YouTubeチャット / 🚪イベント・ルーム / 👥参加者 / ❓ヘルプ / 📊記録
- 位置とサイズは端末に保存する（NPCのスライダーと同じ考え方）のが自然

### 5. 吹き出しの表示時間を長くする
- **いまは4秒固定**（`src/avatar_glb.js` の `speechTimer = setTimeout(clearSpeech, 4000)`）
- 読み切れないので延ばす。**設定で時間を指定できるとなおよい**（loyさん案）
- ⚠ YouTube連動時は吹き出しが本命の表示になるので、ここは効きが大きい

### 6. 運営コメント（固定枠）の位置を調整する
- `src/noticebar.js`。いまは画面上部。z-index 45 で最前面

### 7. ★右上エリアを整理する（いちばん大きい項目）
**loyさんの整理の考え方:**
- **右下は「動画のコントローラー」専用**にする

- 右上エリアを整理してまとめる
