# Unity側への申し送り: 髪を「長さ・髪型・前髪」の3つに分けた（2026-08-06）

宛先: VRChat側（ALLVERSE / clubVERSE のプロキシアバター担当チャット）
差出: Web側（verse_city_web）

## 何が変わったか

**ブラウザ側の髪が、1つのidから3つの組み合わせになりました。**
loyさんの指示「髪の長さ・髪型・前髪の3つで組み合わせの方がいいかな」。

| | 値 | 意味 |
|---|---|---|
| **髪の長さ** `hl` | `long` / `bob` / `short` | ドームの裾の長さ。longが一番長い（あご下より下） |
| **髪型（結い方）** `hs` | `none` / `twin` / `bun` / `pony` | ツインテール・お団子・ポニーテール。`none`は結わない |
| **前髪** `hb` | `std` / `patsun` / `partr` / `partl` | 標準（中央V字）・ぱっつん・右分け・左分け |

3×4×4 = **48通り**。以前は9通り（`long`/`bob`/`short`/`twin`/`bun`/`pony`/`patsun`/`partr`/`partl`）でした。

## 急いで対応する必要はありません

**`av.h`（旧・髪型id）は残してあります。** これまでどおり `h` だけを見ていれば、
いちばん近い髪型が入ってきます（優先順位: 結い方 → 前髪 → 長さ）。

```
{ hl:'bob',   hs:'twin', hb:'std'    } → h = 'twin'
{ hl:'short', hs:'none', hb:'patsun' } → h = 'patsun'
{ hl:'short', hs:'none', hb:'std'    } → h = 'short'
```

⚠ ただし `h` だけでは**長さと前髪の組み合わせが落ちます**
（「ショート＋ぱっつん」も「ロング＋ぱっつん」も同じ `patsun` になる）。
見た目を揃えたいときは `hl`/`hs`/`hb` を見てください。**古い値が来たら**（`hl` が無い）、
`h` から読み替えてください。読み替え表は Web側の `src/hair.js` の `LEGACY_HAIR` が原本です。

| 古い `h` | 長さ | 髪型 | 前髪 |
|---|---|---|---|
| `long` / `bob` / `short` | 同名 | none | std |
| `twin` / `bun` / `pony` | bob | 同名 | std |
| `patsun` / `partr` / `partl` | bob | none | 同名 |
| `none`（ゲスト） | 髪なし | – | – |

## 3Dモデルの持ち方も変わりました

`assets/avatars/` の中身が変わっています（**古い `hair_*.glb` 9個は削除済み**）。

- `hair_<長さ>_<前髪>.glb` … **12個**（long/bob/short × std/patsun/partr/partl）
- `hairx_<結い方>.glb` … **3個**（twin / bun / pony）。**ドームは入っていません。房だけ**です

組み立ては、`hair_<hl>_<hb>` を置いて、`hs` が `none` でなければ `hairx_<hs>` を**重ねるだけ**
（どちらも原点合わせ。位置合わせは不要）。

なぜこの分け方かというと、前髪はドームの生え際と縫い合わせて作っているので切り離すと隙間が出る一方、
結い方（房）は独立しているためです。48通りぜんぶ焼くとファイルが4倍になります。

## 右分け・左分けの向き（間違えやすい）

**「右分け」は本人から見て右**＝正面から見ると**向かって左**に分け目が来ます。

## 追記（2026-08-07）: 目を左右に分けた／運営専用のパラメータが増えた

髪の3分割と同じ日の続きです。**急ぎの対応は要りませんが、GLBのマテリアル名が1つ増えています。**

### 1. 目が左右のマテリアルに分かれた（要対応）

| マテリアル | どこ |
|---|---|
| `MatEye` | **本人の左目**・上（従来は両目ぶんだった） |
| `MatEyeC` | 本人の左目・下 |
| `MatEyeR` | **本人の右目**・上（新規） |
| `MatEyeCR` | **本人の右目**・下（新規） |

⚠ いまのVRC側は `MatEye`/`MatEyeC` しか塗っていないはずなので、そのままだと
**右目が既定色のまま**になります。`MatEyeR`/`MatEyeCR` にも同じ色を塗れば従来どおりの見た目です。

### 2. `av` に増えた値

| キー | 内容 |
|---|---|
| `et` | 左目の**上**の色（0〜13）。**それまで黒で固定だったところ**を選べるようにした |
| `es` | 左右で違う色にしているか（0/1）。**VIP・管理者だけ** |
| `ec2` `et2` | 右目の下／上の色（`es`=1のときだけ意味がある） |
| `sn` `sp` `sw` | 前髪メッシュの本数／位置／太さ（運営専用） |
| `hg` `hi` | 髪のグラデ／インナーカラー（運営専用。0＝なし、1〜14＝色番号+1） |

`sn`/`sp`/`sw`/`hg`/`hi` は**Web側のシェーダーで描いている飾り**なので、
VRC側で再現しなくても構いません（再現したい場合は相談してください）。

### 3. なぜ増えたか

出演者（いま20人・今後増える）に固有性を持たせたい、という要望です。
**アイテムを増やすと運用が破綻する**ので、アイテムではなく**パラメータ**を運営専用にしました。
3Dアセットは1つも増えていません。
