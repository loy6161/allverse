そのままVRC側のアバターに反映されます。

## 2. 組み立て方

1体は **最大3ファイルの組み合わせ**でできています。位置合わせは不要で、
**3つとも原点に置くだけで正しく重なります**（各パーツが最終位置で作られています）。

```
body_<服装> + hair_<髪型> + acc_<アクセ>
```

- `<服装>` = `middle` / `long` / `short`
- `<髪型>` = `long` / `bob` / `short` / `twin` / `bun` / `pony`
- `<アクセ>` = `kemo` / `ahoge` （`none` のときはアクセのファイルを足さない）

組み合わせ数は 3 × 6 × 3 = **54通り**。

### 寸法（実測値）

| 項目 | 値 |
|---|---|
| 身長 | **1.16m**（お団子だけ 1.22m） |
| 足元 | **Y = 0**（そのまま床に置けます） |
| 目の高さ | 0.79m |
| 肩幅 | 約0.53m |

⚠️ **VRChatの人型アバター（約1.6m）より小さい、デフォルメ体型です。**
そのまま置くと子供のように見えます。VRC側で拡大するかは**そちらとloyさんの判断**にお任せします。
（等倍で「ちびキャラの観客」として見せるのも、1.35倍くらいで人間に寄せるのもアリだと思います）

### glTF取り込み時の注意

各ノードは **X軸+90°の回転**を持っています（ジオメトリはZ-up、ノードの回転で立たせている）。
Unityのglyf/glTFインポータは通常これを解決しますが、**取り込み後に向きと前後を必ず確認してください**。
横倒しや前後逆になっていたら、この回転の扱いが原因です。

## 3. 色の塗り分け（ここが本題）

**GLB内のマテリアル名で塗り分けます。名前は固定です。**

| マテリアル名 | 塗る色 | `av` のどれを見るか |
|---|---|---|
| `MatSkin` | 肌 | `av.bc`（肌色8色） |
| `MatHair` | 髪 | `av.hc`（14色） |
| `MatCloth` | 服 | `av.sc`（14色） |
| `MatDark` | 脚（タイツ） | **髪色から作る**（下記） |
| `MatEyeC` | 瞳の色 | `av.ec`（14色） |
| `MatEye` | 目の黒目部分 | 固定 `#191219` |
| `MatEyeGlint` | 目のハイライト | 固定 `#ffffff`（発光扱い・陰影なし） |
| `MatCheek` | チーク | 固定 `#ff96a0` |

**`MatDark`（脚）の作り方**: ブラウザ側では髪色をベースに暗く落とした色を使っています。
再現が面倒なら **`#2a2028` 程度の固定の暗色**でも見た目はほぼ変わりません。

**シェーダー**: ブラウザ側はトゥーン調（陰影2〜3段）です。VRC側は lilToon 等でトゥーンにすると
雰囲気が揃います。厳密な一致は不要という認識です。

### presence.json の `av` の中身

```json
"av": { "h": "short", "o": "middle", "ac": "none",
        "hc": 12, "sc": 12, "bc": 0, "ec": 0, "pl": 9 }
```

| キー | 型 | 意味 |
|---|---|---|
| `h` | 文字列 | 髪型id（`long`/`bob`/`short`/`twin`/`bun`/`pony`） |
| `o` | 文字列 | 服装id（`middle`/`long`/`short`） |
| `ac` | 文字列 | アクセid（`none`/`kemo`/`ahoge`） |
| `hc` `sc` `ec` `pl` | 整数 0〜13 | 髪／服／瞳／ペンライトの色番号（上の14色表） |
| `bc` | 整数 0〜7 | 肌の色番号（上の8色表） |

**知らないidや範囲外の番号が来たら、先頭（index 0 / 配列の1番目）にフォールバックしてください。**
ブラウザ側もそうしています。これで、こちらがパーツを増やしてもVRC側は壊れません。

## 5. 動きについて（任意）

体のGLBには可動パーツが独立ノードとして入っています。**歩行や手ふりを付けたい場合の参考です。**

| ノード名 | 部位 |
|---|---|
| `armL` / `armR` | 左右の腕 |
| `legL` / `legR` | 左右の脚 |
| `eye` / `eyec` / `eyew` | 目（黒・瞳・ハイライト）※まばたきはY方向に潰す |
| `skin` / `cloth` / `hair` / `cheek` | 塗り分け対象の本体 |

ブラウザ側は、腕と脚を支点で回して歩行・手ふり・拍手などをさせています。
**支点はノードのジオメトリ原点ではなく、ワールド境界の上端**を使ってください
（各ノードが回転を持っているため、ジオメトリのバウンディングボックスから取ると支点がずれます）。

ブラウザ側のエモートは6種です（👋手をふる／👏拍手／⤴️ジャンプ／🕺おどる／💗ハート／🔦ペンライト）。
**現状 presence.json にエモート状態は載せていません。**必要なら `v=2` で相談させてください。
