# ワールドの目標イメージ（VRChat版 clubVERSE / VERSE CITY）

2026-07-28、loyさんから実際のVRChat内 clubVERSE のスクリーンショットを共有された。
ブラウザ版ワールドを作り込む際の**目標となる絵**。現在のブラウザ版は仮モデルであり、ここを目指す。

## 見た目の構成要素（スクショから読み取れるもの）

| 要素 | 内容 |
|---|---|
| **空・背景** | 深い紺色の夜空。**巨大な月**が正面上空に浮かぶ（クレーターまで見える大サイズ） |
| **構造物** | 黒〜濃灰の**細長い板状モノリス**が林立し、会場を囲む。縦のリズムで空間を作っている |
| **ネオン** | 温白色〜オレンジの**V字/への字の発光ライン**が左右対称に配置。強いブルームで光が滲む |
| **床** | **鏡面反射する床**。ネオンと人影が映り込み、空間の奥行きと高級感を出している |
| **ステージ** | 円形の低いステージ。左右にPAスピーカー、前面にモニタースピーカー。奥にclubVERSEロゴ |
| **サイドスクリーン** | 左右に大型の映像面（片方にclubVERSEロゴ／もう片方に映像） |
| **粒子** | 空間に**小さな光の粒**が舞っている（ホコリ/紙吹雪的な演出） |
| **観客** | 手前に多数のアバター。**色とりどりのペンライト**を持っている（青・シアン・黄・ピンク等） |
| **配色** | 暖色（オレンジ〜白）のネオン × 紺色の空 × 黒い構造物。現在のブラウザ版（シアン/マゼンタ主体）とは方向性が違う |

## 現在のブラウザ版との差分（作り込む際の課題）

1. **配色**: ブラウザ版はシアン/マゼンタのサイバー系。本物は**暖色ネオン×紺**の落ち着いた高級感 → 寄せるべき
2. **月**: 象徴的な要素。ブラウザ版には無い（追加は容易・効果大）
3. **モノリス群**: ブラウザ版は「窓のあるビル」。本物は**無機質な板の林立** → 差し替えると一気に近づく
4. **鏡面床**: 本物の空気感の核。ブラウザでは負荷が高いので、簡易反射（反射プローブ的なフェイク）で寄せる
5. **粒子**: 軽量なパーティクルで再現可能
6. **観客のペンライト**: フェイズ2以降のエモート「penlight」と接続すると本物に近づく

## 実装時の優先順位（案）

効果/コスト比の高い順: ①配色の変更 → ②月の追加 → ③モノリス群への差し替え → ④粒子 → ⑤簡易鏡面床

※ Unityの本物ワールドをglTFで持ってくる案とは別軸。こちらは「ブラウザ側で似せて作る」アプローチ。
