## ⚠ 食い違っていた前提（ここだけ読んでください）

依頼では「ループ系（wave/clap/dance/penlight）は `em` の間ずっと再生、`none` に戻ったら停止」となっていましたが、
**ブラウザ会場のエモートは6種すべて「決まった長さで1回だけ」再生される作り**です。
「押している間ずっと」という状態はそもそも存在しません。

したがって:

- **「`none` に戻る」という合図は送れません**（そういう状態を持っていないため）
- 代わりに **「いつ・何を・何秒間」** を送ります。**再生が終わると `em` 自体が消えます**
- VRChat側は **「`em` が無い＝通常（待機）」** と読んでください。これは既存の `c[]`（直近の発言）と同じ考え方です

**全部がワンショットです。** ループ再生の分岐は要りません。

## 実際の形（本番でもう出ています）

```json
{ "rm":1, "n":"名前", "x":.., "z":.., "r":.., "av":{...},
  "em": "wave",       // 再生中のエモートid。終わると項目ごと消える
  "emt": 1785697508,  // 開始時刻（UNIX秒）
  "emd": 2.5          // 長さ（秒）← 依頼になかった追加分
}
```

### `emd`（長さ）を足した理由

**VRChat側で長さを二重に定義しなくて済むようにするためです。**
ブラウザ会場でエモートの長さを調整したとき、`emd` を見ていればVRChat側を直さなくても揃います。
数値を焼き込むと、片方だけ直したときに必ずズレます。

不要ならもちろん無視して構いません（VRChat側で固定値を持つ形でも動きます）。

### `em` の値と長さ

| id | 内容 | 長さ | 備考 |
|---|---|---|---|
| `wave` | 手をふる 👋 | 2.5秒 | |
| `clap` | 拍手 👏 | 2.5秒 | 1秒に3打 |
| `jump` | ジャンプ ⤴️ | 2.0秒 | **2秒の中で3回跳ねる**（エモートバーのボタン） |
| `dance` | おどる 🕺 | 4.0秒 | |
| `heart` | ハート 💗 | 3.0秒 | |
| `penlight` | ペンライト 🔦 | 4.0秒 | ペンライトの色は `av.pl` |
| **`hop`** | **1回だけ跳ぶ** | **0.72秒** | **★新設。下記参照** |

- **未知のidは `none` 扱い**でお願いします（そちらの方針どおり）。こちらも知らないidは弾いています。
- `v` は **1 のまま**です。増えた項目はすべて任意なので、いまのVRChat側の読み取りは壊れません。

## ★ `hop` を新設しました（確認事項2への回答）

### 何が起きていたか

**ブラウザ会場にはジャンプが2つあります。**

| | 中身 |
|---|---|
| **Spaceキー** | **本物の移動**。重力つきでアバターの高さが実際に変わる（初速5.0 / 重力14.0 → 滞空 約0.72秒・最高 約0.89m） |
| **⤴️ボタン** | エモート。2秒の間に3回跳ねるアニメーション |

ところが**これまで両方とも同じ `jump` として送られていました**。
そのため「Spaceで1回跳んだ人が、他人の画面では3回跳ねて見える」という状態でした。

### そちらの推測について

> ※もし実際に座標yを上下させているなら、その場合は presence の座標だけで表現される＝別途不要

**半分あたりです。** 座標yは実際に上下していますが、**presence には y 自体がありません**（送っているのは x・z・向き の3つだけ）。
なので座標だけでは表現できず、**エモートとして送る必要があります**。

### 対処（loyさん判断・2026-08-03）

> ジャンプ1回のエモートを1種類増やしてそれをspaceキーの時におくればいい。
> ジャンプ1回のエモートはボタンに入れないで内部でもっていればいい。

- **`hop`（1回だけ跳ぶ・0.72秒）を新設**し、**Spaceキーはこちらを送る**ようにしました
- **`hop` はエモートバーに出しません**（内部専用）。お客さんから見える選択肢は今までどおり6種です
- **`hop` の弧は本物の物理と同じ式**にしてあります。本人の画面と他人の画面で跳び方が一致します
- **`jump`（3回跳ね）は⤴️ボタン専用**として残しました

**VRChat側では `hop` を「1回だけ跳ぶ」として再生してください。** `jump` と混ぜないでください。
