# アバター素材のライセンス要件（重要）

ブラウザ版は**モデルデータをブラウザへ配信する**仕組みなので、
アバター素材に求められる条件が、VRChat用アバターの一般的な利用条件とは根本的に違う。

## 満たさなければならない条件

| 条件 | 理由 |
|---|---|
| **抽出可能な形での再配布が許諾されている** | Webはモデルファイル（GLB等）をブラウザへ送る＝誰でもダウンロードできる状態になる。「データを取り出せる形での再配布禁止」の素材は**構造的に使えない** |
| **改変が許諾されている** | 色替え・軽量化・ボーン調整が必要 |
| **商用利用が許諾されている** | フェイズ3で有料イベント・グッズ販売を行う計画のため |
| **二次創作でない（または原作者の許諾がある）** | 二次創作物は、配布者が自由な条件を付けても原作の権利は残る |

→ 実質的に **CC0 / パブリックドメイン相当、または作者と個別に契約** が必要。

## 判断した事例

### ✕ 260517_lowpoly_sasikizu_fanart_avatar（rururirafu 氏 / BOOTH 8379031）
2026-07-29 検討・**採用不可**と判断。

- **CC0ではない**（VN3ライセンス）
- 商品ページに「データを取り出せる形での再配布(ユーザ間であっても)を禁止します」と明記
  → Web配信そのものがこれに抵触する
- 「#SASIKIZU さまの作品をもとに制作した2次創作作品」＝原作の権利が別に存在する
- 形式も unitypackage / FBX で、Web用にはGLB等への変換が必要（変換＝改変＋再配布）

## 使える可能性がある調達先

1. **自分たちで作る**（VRoid Studio等）— 権利がすべて自分たちにあるので制約ゼロ。最有力
2. **作者に個別に依頼する**（Web配信・改変・商用の許諾を明記した契約を交わす）
3. **明確にCC0の素材**（例: Kenney, Quaternius などのゲーム向けCC0アセット）
   — ただし二次創作でないこと・CC0表記の一次情報を必ず確認する
4. **ユーザー自身のVRM持ち込み**（アップロードした本人の責任範囲。プリセットには使えない）

## 運用ルール

- 素材を採用する前に、**必ず一次情報（商品ページ・ライセンス本文）で上記4条件を確認**し、本ファイルに記録する
- 「無料」「フリー」という表記だけで判断しない。無料と再配布可は別物
