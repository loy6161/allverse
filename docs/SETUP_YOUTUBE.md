# SETUP_YOUTUBE — ワールド内チャットをYouTube配信のコメント欄へ流す

最終更新: 2026-07-30

これは**loyさんの作業手順**です。上から順に進めてください。
サーバー側の実装は完了していて、あとは設定だけで動きます。

---

## 先に知っておくこと（重要）

### 1日に送れる回数が少ない

YouTube Data API の枠は既定で **1日10,000ユニット**。
コメント投稿は1回 **50ユニット**なので、**1日200回**しか投稿できません。

そのままだと配信1本ももたないので、**数秒ぶんの発言を1通にまとめて**送るようにしてあります
（`なまえ: 本文 / なまえ: 本文` の形、200文字まで）。
それでも足りない場合は、Google Cloud のコンソールから**枠の増量を申請**できます（無料・審査あり）。
枠が増えたら Render の環境変数 `YT_QUOTA_PER_DAY` を上げてください。

残り回数は 🚪 パネルの「配信のコメント欄へ転送」に出ます。
使い切ったら投稿を止めて、ワールド内に「今日はもう送れません」と出ます（黙って捨てません）。

### 投稿は「配信者のアカウント名義」になる

参加者それぞれのYouTubeアカウントで投稿する形にはしていません。
投稿に必要な権限（`youtube.force-ssl`）はGoogleの**制限付きスコープ**で、
全参加者に許可させるには**アプリ審査と第三者によるセキュリティ評価**が必要になり、
費用も期間もかかるためです。

**配信者のアカウント1つだけが許可する**形なら、テストユーザー枠（100人まで）に収まるので
審査なしで今日から動きます。コメント欄には配信者の名前で
`なまえ: 本文` の形で出ます。

### 配信中でないと送れません

アーカイブや通常動画のコメント欄には投稿できません（YouTubeの仕様）。
配信中でないときは「配信中ではないため送れませんでした」と出ます。

### お金はかかりません

YouTube Data API は無料です（枠の制限だけ）。増枠申請も無料です。

## A. Google Cloud の設定

### A-1. クライアントシークレットを用意する

1. https://console.cloud.google.com/ を開き、ALLVERSE用のプロジェクトを選ぶ
   （ログイン設定のときに作ったものと同じ）
2. 左メニュー **「APIとサービス」→「認証情報」**
3. ログイン用に作った **OAuth 2.0 クライアント ID**（ウェブアプリケーション）をクリック
4. 右上に **クライアントシークレット**があります。表示してコピー
   - 見当たらない場合は「シークレットを追加」で新しく作れます
   - ⚠️ **この値はチャットにも貼らないでください。** Render の環境変数にだけ入れます

### A-2. 戻り先URLを登録する

同じ画面の **「承認済みのリダイレクト URI」** に、次の1行を追加して保存:

```
https://allverse.onrender.com/api/yt/callback
```

ローカルでも試したい場合は、これも追加:

```
http://localhost:5179/api/yt/callback
```

### A-3. YouTube Data API を有効にする

1. 左メニュー **「APIとサービス」→「ライブラリ」**
2. `YouTube Data API v3` を検索して開く
3. **「有効にする」**

### A-4. スコープを追加する

1. 左メニュー **「APIとサービス」→「OAuth 同意画面」→「データアクセス」**
2. **「スコープを追加または削除」**
3. `https://www.googleapis.com/auth/youtube.force-ssl` を探してチェック → 更新 → 保存
   - 「制限付き」と表示されますが、**テストユーザーとして使うぶんには審査不要**です

### A-5. 配信者アカウントをテストユーザーに追加

1. 「OAuth 同意画面」→ **「対象」**
2. **テストユーザー**に、**配信に使うYouTubeチャンネルのGoogleアカウント**を追加
   - 管理者アカウントと違う場合は、配信用の方を入れてください

---

## B. Render の設定

1. https://dashboard.render.com/ → **allverse** → 左メニュー **Environment**
2. **Add Environment Variable** で以下を追加:

| Key | Value |
|---|---|
| `GOOGLE_CLIENT_SECRET` | A-1でコピーしたシークレット |
| `PUBLIC_URL` | `https://allverse.onrender.com` |

3. 保存すると自動で再デプロイされます（1〜2分）

> `YT_QUOTA_PER_DAY` は増枠が通るまで設定不要です（既定10000）。

---

## C. 接続する（画面から）

1. 本番 https://allverse.onrender.com に**管理者アカウントでログイン**して入場
2. 右下の **🚪** を開く → いちばん下の **「配信のコメント欄へ転送」**
3. **「YouTubeに接続」** を押す → 新しいタブでGoogleの許可画面
   - 「このアプリは Google で確認されていません」と出たら、
     **詳細 → （安全ではないページ）に移動** を押す（テストユーザーなので正常です）
   - **配信に使うチャンネルのアカウント**で許可してください
4. 「✅ YouTubeに接続しました（チャンネル: ○○）」と出れば完了。タブを閉じる
5. 🚪 パネルに戻り、**「転送をONにする」**にチェック

### 参加者側の見え方

転送がONになると、参加者のチャット欄に **📺 ボタン**が出ます。

- **既定はOFF**。押したときだけ配信のコメント欄にも送られます
- 押すと赤く光り、「⚠️ この発言は配信のコメント欄にも出ます（あとから消せません）」と警告が出ます
- 配信に出た発言は取り消せないので、うっかり送らない作りにしています

## D. 困ったときは

| 症状 | 見るところ |
|---|---|
| 「配信のコメント欄へ転送」の欄が「まだ設定されていません」 | `GOOGLE_CLIENT_SECRET` が Render に入っているか。入れた直後は再デプロイ待ち |
| 接続ボタンでエラー | A-2 のリダイレクトURIが1文字ずれていないか |
| 「再認可の情報が受け取れませんでした」 | https://myaccount.google.com/permissions で ALLVERSE のアクセスを一度削除してからやり直す |
| 送っても配信に出ない | 配信中か。イベントに設定した動画IDが、いま配信中のものか |
| 「今日の送信上限に達しました」 | 1日200回を使い切った。翌日（太平洋時間0時）に戻る。増枠申請を検討 |
| サーバー再起動で接続が切れる | Turso（永続化）が有効か。`/api/status` の `store.ready` を確認 |

サーバーの状態は https://allverse.onrender.com/api/status の `youtube` に出ます
（トークンそのものは絶対に出しません）。
