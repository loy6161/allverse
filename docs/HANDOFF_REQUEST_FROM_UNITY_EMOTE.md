# Unity側からの依頼：presence にエモート状態を載せてほしい（VR客席で再生したい）

作成: 2026-08-02 ／ 発行元: Unity/VRChat側（VERSE CITY2025）
宛先: ALLVERSE WEB側（Worker/presence 担当）
関連: HANDOFF_UNITY_3_AVATAR §5（「エモート同期は v=2 で相談」保留分）／ HANDOFF_UNITY_5（Worker移管）

---

## お願い一言

**presence.json の `web[]` 各エントリに「今この人が何のエモート中か」を1フィールド足してほしい。**
VR側でプロキシアバターに手ふり/拍手/ジャンプ/踊り/ハート/ペンライトを再生します。

## 希望フォーマット（案・そちらで調整可）

`web[]` の各要素に、オプションで：

```json
{ "rm":1, "n":"名前", "x":.., "z":.., "r":.., "av":{...},
  "em": "wave",      // ← 追加希望。現在のエモートid（無ければ "none" か省略）
  "emt": 1785400000  // ← 任意。エモート開始時刻(UNIX秒)。ワンショット(jump/heart)の再生同期用
}
```

### `em` の値（ブラウザの6種に対応）

| id | 内容 | 再生タイプ |
|---|---|---|
| `none`（or 省略） | 通常（待機） | — |
| `wave` | 手をふる 👋 | ループ（emの間） |
| `clap` | 拍手 👏 | ループ |
| `dance` | おどる 🕺 | ループ |
| `penlight` | ペンライト 🔦 | ループ |
| `jump` | ジャンプ ⤴️ | ワンショット（emt起点で1回） |
| `heart` | ハート 💗 | ワンショット |

- **ループ系**（wave/clap/dance/penlight）：`em` がその値の間ずっと再生。値が `none` に戻ったら停止。
- **ワンショット系**（jump/heart）：`emt`（開始時刻）が更新されるたびに1回再生。押しっぱなしでなくトリガーでOK。
- **未知のidは `none` 扱い**（そちらの既存フォールバック方針と同じでお願いします）。

## こちらの実装状況

- VR側の**再生ロジックはこの案に合わせて先に組みます**（`em` を読んでAnimator/Transformで再生）。
- なので **`em`/`emt` を presence に流し始めてくれれば、VR側は追加改修なしで動く**予定です。
- スキーマ変更になるので、そちら判断で `v=2` に上げるならこちらも `v` を見て両対応します（当面 `em` が無くても既存動作は壊れない設計にします）。

## 確認したいこと

1. この `em`/`emt` の形で問題ないか（ブラウザ側で持っているエモート状態をそのまま流せるか）
2. `jump` は「エモート」扱いでいいか（位置のyジャンプではなくアニメとして。※もし実際に座標yを上下させているなら、その場合は presence の座標だけで表現される＝別途不要、も有り得るので教えてください）
3. 流し始める時期（こちらの再生側が出来たら合わせたい）
