# 申し送り⑨: 利き手を選べるようにしました（`av` に `hd` を追加）

種別: **実装済みの事後共有＋任意の対応依頼**

---

## 一言でいうと

**こちらの片手エモートが左手になっていました。そちらに合わせて右手に直しました。**
あわせて、**利き手を選べる**ようにしたので、`av` に `hd` が増えます。

**そちらが何もしなくても壊れません。** 既定は右手なので、いまの実装のままで大多数は一致します。
左利きを選んだ人だけ、VRC側では右手のままになります。

---

## ① まず謝罪と訂正：こちらが左手でした

そちらの実装が右手で、**こちらが左手**でした。**こちらのバグです。**

原因は、GLB内のオブジェクト名と実体が逆だったことです。

| GLB内の名前 | 実際の腕 |
|---|---|
| `armR` | **アバターの左腕** |
| `armL` | **アバターの右腕** |

（実測: 向きを0にしたとき `armR` の中心が x=+0.18、`armL` が x=−0.18。
アバターの前方は +z なので、右手は −x 側＝`armL` の方）

片手のエモートは全部 `armR` を使っていたので、**ずっと左手で振っていました。**
名前を信じて確認していませんでした。**いまは右手に直っています。**

対象は **手をふる / ペンライト / コブシを上げる / 乾杯** の4つと、
**持ち物（ペンライト・ビールジョッキ）** です。両手を使うもの（踊る・ハート・星・花火）は元から左右対称なので変わりません。

---

## ② `av.hd` を追加（利き手）

```json
"av": { "h":"bob", "o":"middle", "ac":"wing+halo", "hc":3, "sc":4, "bc":8, "ec":2, "pl":5, "ht":"mid", "hd":"r" }
```

| 値 | 意味 |
|---|---|
| `"r"` | **右利き（既定）** |
| `"l"` | 左利き |

- **省略・未知の値はすべて `r`（右）** として扱ってください。こちらもそうしています
- ⚠ **ここを左に倒さないでください。** 未指定を左にすると、
  **設定を持っていない古い人が全員左利きになり、また食い違います**
- 入場画面の「利き手」で選びます。既定は右で、ランダムにはしていません

### そちらが何もしなかった場合

**右利きの人（＝ほぼ全員）は一致します。** 左利きを選んだ人だけ、
VRC側では右手のまま振ります。壊れはしません。

### お願い（対応するなら）

**`hd` が `"l"` のときだけ、片手の動きと持ち物を左右反転してください。**
対象はこちらと同じ4つ（手をふる／ペンライト／コブシ／乾杯）と持ち物です。

---

## お願いのまとめ

1. `hd` を読んで左右を切り替える（対応するかはそちらの判断で構いません）
2. ⚠ **省略・未知の値は必ず `r`（右）扱い**にしてください
3. 困る点があれば教えてください
