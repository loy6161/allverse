# VERSE CITY Web

clubVERSE のブラウザ版メタバース。フェーズ①（プリセットアバター＋歩き回り＋チャット）の
**リアルタイムマルチプレイ実装済み**（ローカル環境）。

## このプロジェクトの目的（北極星）

> **ALLVERSEのファン全員——VRができる人も、配信で観るだけの人も——が「一緒に」ライブを見られる場所を作る。**

- VRChatに代わるプラットフォームを作るのではない。VRChatから人を移すのでもない
- VR勢はVRChatのVERSE CITYに、配信勢・スマホ勢はここに。相互プレゼンス連携で**両方が「同じ会場にいる」**
- 判断に迷ったら「配信勢がVR勢と同じ熱量で楽しめるか」を基準にする
- 商用の自由・荒らし耐性は、この夢を持続可能にするための手段（目的ではない）

## 現状の位置づけ

- **リアルタイム同期: 実装済み**（server/ のWebSocketサーバー。複数ブラウザで相互にアバター・移動・チャットが同期）
- サーバー未起動時は自動で**オフラインデモモード**（NPCが歩き回る従来の疑似マルチ）にフォールバック
- `?npc=1` を付けるとネットワークモードでもNPC（賑やかし）を追加できる
- ワールドは仮の VERSE CITY（ネオンシティ×ライブステージ）。将来 Unity から glTF 書き出しした本物のワールドに差し替える
- 会員認証・VERSE COIN 連携は未接続（Allverse_Portal と連携予定）
- デプロイ（ホスティング）は未実施。無料枠の候補選定はこれから

## 起動方法

```
# 1) 同期サーバー（初回のみ server/ で npm install）
cd verse_city_web/server && npm start        # ポート5179

# 2) クライアント（ビルド不要の静的サイト。Three.jsはCDN importmap）
npx -y serve -l 5178 verse_city_web
```

→ http://localhost:5178 を開く（複数タブ/複数端末で開くと同じワールドに入れる）
→ サーバー状態: http://localhost:5179 ／ VRC連携用: http://localhost:5179/api/presence.json

## ロードマップ（2026-07-18 確定・3フェイズ構成）

### フェイズ1: 両世界の窓 —「ブラウザ勢・YouTubeコメント勢がVRCにも現れる」
- ブラウザ会場（本リポジトリ）＋ presence.json → ALLVERSE Worker → VRCワールドに出現（Unity側と合意済み）
- 現状: ブラウザ会場のマルチプレイ実装済み・デプロイ待ち。Unity側ギミック開発中
- この期間に育てる機能: VRM対応（レギュラーメンバー）、ボイチャ、ルーム一覧・友達合流、テクスチャカスタム（承認制）

### フェイズ2: 交流の場 —「ブラウザ会場にVR（WebXR）でも入れる」
- VRヘッドセットからブラウザ会場に直接入場 → **ブラウザ勢とVR勢がここで初めて直接交流できる**
- **ライブ自体はフェイズ1と同じ形のまま**（ライブ本体はVRChat開催・ブラウザ勢はスクリーンでYouTube視聴）。この空間の役割は変わらない
- 制約を逆手に取る: VRモードではYouTubeスクリーンが見えないため、**有料アイテムの展示・販売、交流イベントを主目的の空間にする**(映像視聴はデスクトップ・スマホ勢の役割のまま）
- VRM対応がこのフェイズの体験の質を左右する（VR勢が「自分の姿」で来られること）
- **ネーミング候補**: 「ALLVERSE parallel」「VERSE CITY parallel」——VRChatのVERSE CITYと"並行して存在するもう一つの会場"というコンセプト（検討中）

### フェイズ3: 自前ライブ会場 —「特別イベントはここで完結」
- 演者本人がアバターでステージ出演（VMCプロトコル連携＋音声リアルタイム配信）。映像配信不要でコスト極小
- 有料チケット（ポータル会員×VERSE COIN）、グッズ・アバター販売、投げ銭。**VRChatに行かなくてもここで完結**
- ブラウザ勢とVR勢が「本当の意味で一緒に」同じライブを体験する——北極星の実現形
- 対cluster差別化: VRChat文化圏準拠のクオリティ／手数料なし・データ自前／VERSE COIN一体化
- 設計原則: 持ち込みはデータのみ（VRM・テクスチャ、検査/承認制）。実行コードの持ち込みは永久不可。表現手段は運営がキュレーションして提供（＝コイン消費先）。ギミック基盤は「ワールド状態同期＋スタッフ操作卓」
- 商用化前の宿題: 音楽の権利処理（カバー曲）、VERSE COINの資金決済法整理（ポータル決済設計と同時に）
